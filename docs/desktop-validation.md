## 边界

此版本实现设备模式重连及 PID 变化处理，但本轮没有进行物理拔插、锁屏、Wi-Fi、多设备、多系统版本和长时间压力测试；不得宣称这些场景已全部验证，也不宣称严格零丢失。启发式解析的级别与分组不等于系统原始语义，原始流保留用于复核。

启动采集需要 Xcode，设备日志依赖本机 libimobiledevice，尚未内置依赖、Developer ID 签名或公证。本轮目标是可在本机使用的完整桌面工具，正式公开发行另行处理。
